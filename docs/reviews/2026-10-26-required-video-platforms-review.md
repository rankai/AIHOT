## 1. 官方证据逐项核对

读取的是 Redfox 公开文档接口 `GET /story/web/api/doc/detail/no/{operationId}`，不是 `/story/api/…` 业务调用。六份文档均返回 `code=2000`，接口状态为 1；这只说明目录状态，不证明真实接口成功。下表链接直接指向本轮读取的官方文档。

| 接口 | 已确认的输入与输出 | 不足与实际影响 |
| --- | --- | --- |
| [作品搜索 E7G00COY](https://redfox.hk/story/web/api/doc/detail/no/E7G00COY) | 输入 `keyword`，可带排序/分页等。逐项 `list[].videoUrl` 明确为视频 URL，`thumbUrl/coverUrl` 分别为缩略图/封面；成功示例含非空视频地址。 | 字段表有 `videoId`，完整成功示例却未返回它；没有稳定作者 ID、原文分享链接或 `workType`。有视频地址不能自动授予作者归属。 |
| [账号作品 OVUTOTCV](https://redfox.hk/story/web/api/doc/detail/no/OVUTOTCV) | 按 `nickname` 精确查询并分页。作品字段和视频/封面区分同上，成功示例含非空视频地址。 | 昵称不是稳定身份；成功示例同样没有 `videoId`。仍需人工逐项确认作者、作品和原文的关系。 |

这些证据足以制定“列表视频地址 → 人工核验入库 → 保存”的代码合同，不足以宣称所有列表项都是视频、可完全无人值守或所有媒体均能保存。`videoUrl` 为空、仅封面或出现明确非视频矛盾时，不登记保存；不能为推测类型先调用收费解析。

文档没有下载流实测结果。本轮未对示例媒体地址执行 HEAD/GET；报告不保存签名媒体 URL 或原始完整示例。官方文档中未出现的字段不由其他平台的响应形状补造。

## 2. 最小流程与连接点

有效订阅 `E7G00COY/OVUTOTCV` 的执行结果 → 管理员核实本条原文和作者，选择已启用的隔离 external 信源 → 现有人工导入事务保存材料及视频事实 → 原 `registerImportedVideo` 核验订阅开关、版本、作者与回执 → 优先保存已收 `videoUrl`，必要时按原规则使用 `U2NJ13MW` → 原执行记录和私有素材查看。

现有代码已经提供以下部分，不能重复建设：

- [视频号解析与结果](../../packages/backend/src/providers/redfox/shipinhao.ts)：保留上游原始项，不把昵称或请求 ID 当成作者/作品证据。
- [人工入库](../../packages/backend/src/providers/redfox/import-manual-work.ts)：逐项原文与作者依据、隔离信源限制、材料去重、回执和审计。
- [订阅登记](../../packages/backend/src/sources/subscription-video.ts)：当前 `collection` 来源、单订阅成员、执行版本、同次回执；独立查询不会派生订阅下载。
- [候选提取](../../packages/backend/src/sources/subscription-video-candidates.ts)：已经覆盖 `E7G00COY/OVUTOTCV/OE4KUEUO` 的 `videoUrl`，也已有固定解析器。
- [执行器](../../packages/backend/src/providers/operations/subscription-video.ts)：预算、回执恢复、受限文件传输、文件复用、保存结果；沿用原私有素材及清理任务。

真正待改的只有：视频判断用于材料和登记的同一小规则、历史证据规则与空 ID 一致性、现有能力文案及人工导入费用说明。详细文件范围及验收见[完整方案第 3.2 节](../subscription-video-download-plan.md#32-视频号最小补齐方案已实现本地验收通过)。不新增详情连接、HTTP 接口、表、列、状态、队列或框架。

`videoId` 缺失时，沿用人工核实原文的现有 `identity_key`，不合成 ID。相同规范化原文可沿原规则跨订阅复用；不同分享链接是否同一作品未被证明，不承诺跨链接去重。原结果重复导入仍幂等返回，不通过修改早退逻辑追补旧视频。无需迁移、历史扫描或补下载。

### 架构、费用和恢复边界

- 采集供应商与固定 Redfox 解析服务继续分开；解析走 `redfox.media` 和原回执，直接文件传输不伪装供应商 API 请求次数。次数预算不被表述成金额保证。
- 当前入库事务登记意图，下载使用原本地操作与 `operations.execute`，不占用主采集的 `active_run_id`；不为视频号单建状态或后台入口。
- 当前版本、父结果/回执尝试、订阅开关和材料真实作者仍是原所有权检查；不能把独立查询改成 `collection`，也不能补挂某个订阅借用授权。
- 已收解析回执重放、未知请求有界恢复、停用/切换后的收尾仍归原执行器；本次不新增第二种重试策略。具体真实验收继续遵守当次授权的失败即停边界。
- 已有文件按可靠身份复用、不续期；首次保存起 30 天由原清理任务删除并保留墓碑。视频号 URL 身份的跨链接去重没有证据，不用新映射表掩盖。
- 50 MB、已有低清候选、后台过大占位、私有权限沿用原行为；不转码、不合流、不自动发布，也不改变前台封面和原站链接。
