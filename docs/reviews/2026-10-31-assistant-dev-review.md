## 已确认并修复的问题

| 问题及触发条件 | 修复和实际证据 |
| --- | --- |
| 总预算已开、会员池为零或缺失时，助手仍显示可用并接受新任务、占用积分，随后才进入预算等待 | `requireAvailable` 同时检查会员池配置；新报价和新提交拒绝不可用配置，已接受命令先按原身份幂等返回。回归覆盖零值、缺失、关闭预算后的原命令重放；浏览器关闭会员池后显示原因、发送禁用、无报价，钱包与费用记录均未变化。运行中临时耗尽额度仍沿用共享回执等待机制。 |
| 模型只返回文字且没有工具/稿件交付时，结果已存却仍允许停止后继续，可能重复保存相同回复 | 已提交的模型 decision 不再重复写消息、结果或工具；无可推进工具的当前步骤保持待核对，用户与管理员恢复接口均拒绝无效继续，页面不再提供继续按钮。测试覆盖旧响应重放、消息/结果/费用数量和真实外发次数；已有响应但 decision 未提交的正常恢复仍通过。 |
| 认证完成后账号被停用，新补充回答仍可写入并恢复任务 | 新答案写入前在现有锁序中重新验证账号状态；相同已接受答案的安全回放保留。用例证明停用后的新答案返回拒绝且消息、revision、phase 不变。 |
| 两次不同目的的模型调用都显示“创作接口已返回”，看起来像重复执行 | 仅用现有有序动作记录细化已完成调用：选择技能显示“已选择创作技能”，稿件内容返回显示“稿件内容已返回”，独立保存成功仍显示“稿件已保存”。检索建议显示“已提出笔记检索需求”，不能提前宣称已经查询；多个动作或缺少证据时保留中性描述。未隐藏或合并真实调用，不按调用序号猜测意图。 |

## 浏览器与账本验收

路径：本地 Web 3400 → 真实 API / operation 队列 3401 → 模型及查询桩 3402 → 隔离 UI 测试库。ego-browser 空间 26。内容为合成材料，7 积分创作价和 3 积分检索价仅为测试值。

- 首次发送免费建会话；取消报价保留需求，尚无用户消息、调用或费用记录；确认后才保存用户消息和执行。
- 慢速模型期间显示真实调用动作；完成后根据持久动作显示技能、内容返回及保存，未显示供应商品牌或虚构热门爆文动作。
- 手机切换稿件，编辑保存版本 2，再引用返回对话，引用确为版本 2。继续修改、停止、读取迟到结果、继续原任务后仍只有两条原需求与两张对应创作费用记录。
- 小红书需求进入补充问题，回答沿用原任务，没有新创作报价。步骤折叠后批准按钮仍可用；明确批准后才显示“正在查询‘验收相机’”，最终保存 1 条本地参考来源及标明部分交付的稿件。
- 纯文字异常回复只保存一条，进入待核对；停止后没有无效继续按钮。费用仍按既有核对流程保留，没有自动释放再购买。
- 会员池关闭时填入新需求，发送禁用、无报价；钱包一直为 available=969 / reserved=7，费用记录始终 5 张。结束后恢复的只是本地测试夹具额度。
