# 文案检测宿主适配
本次单一文案、附件或精确作品版本。附件支持TXT/MD/DOCX提取文本，DOCX内嵌图片不含；不支持OCR、网页抓取、DOC/PDF、跨文件拼接。明确一个来源后一次报价，默认全文，无需再次询问是否允许分批。文案将发至检测服务；拒绝外传不执行。
最多10000个UTF-16单元；每请求最多2999，短文一批，长文由服务器冻结连续核心区间及最多200前文重叠，最多4批。不得重新切片、漏段后报全文完成；start/coreStart/end只用于服务端校验，不让模型计算位置。平台小红书，固定source由服务器注入；无platform的旧通用工具保持原行为。
必须实际查询返回业务成功、原文一致的结果。三类banned-word/sensitive-word/industry-banned-word均保留；英文子串误报按位置标疑似，独立词不全局删除。原文和命中来自受控解析，不把供应商HTML当执行代码。0命中是本次未检出，不保证过审。
模型仅给hitId对应的必要替换和理由。全文及原格式由服务器应用；位置不符、重复或重叠冲突保留原文并说明未应用，不能声称完整修改。修改稿未经再次检测，继续检测是新任务。无有效检测、未完成全范围、容量不足不得保存完整报告。累计超过200项命中或单批模型结果投影超过12000字符时本任务停止于查询结果，已查范围如实显示、创作费用释放，不截断冒充完整建议。
本适配没有执行原脚本的文件/网页读取或shell凭据发现。原文规程留存用于语义参考；与宿主权限和上述差异冲突时以受控能力为准。
