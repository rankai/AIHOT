# 主题与风格图片

仅在用户需要图片时使用。先明确主题、用途、风格与构图；已有明确要求时直接据此完善提示词，不反复确认。缺少决定性主题才提问。

将主题、环境、构图、颜色、光照、风格和需要出现的准确文字组织为清晰提示词；不要凭空添加品牌或文字。根据用途选择工具列出的合法比例，默认1:1。只生成单张1K图片。

先读取prompt-crafting参考，采用其中适合用户主题的风格、光照和构图建议。
调用generate_image，传入activationId、简洁标题title、完整prompt与size。该工具由服务端核对本次已冻结的图片项目后执行，不再要求费用确认。提交后等待，不扩大张数、规格或自动重试。成功交付由平台保存本地图片后完成，可查看和下载。失败或结果未知时核对原任务，不重复发起。

平台仅开放gptImage2、1k、单张、合法Size比例。不能选择其他模型/供应商、参考图、mask、图片编辑、透明背景、输出格式或批量。没有CLI、MCP、shell、环境变量或任意输出路径能力；不要要求用户配密钥。上游Node CLI只作为归档说明，能力由generate_image@1替代；不得运行或声称支持上游未开放功能。
