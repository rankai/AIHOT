# 通用图片创作（直接模式）

来源固定为 `chemny/ai-image-generator@90736de1c8f6b672a235e43113d7a90c86e73119`。本平台采用其默认 Direct 模式：用户提示词原样交给图片模型，只把尺寸和用途解析成受支持的比例，不重写、不扩写、不翻译，也不替用户增加风格、构图或负面提示词。

先读取 `upstream-skill`、`platform-specs` 和 `integration-contract`。本平台只开放 Direct 模式；上游 Pro 模式不在当前范围。用户明确要求 Pro 或提示词检查时说明暂不支持，不能自行补写提示词或切换模式。

## 比例解析

按以下顺序选择工具列出的合法比例：

1. 用户明确给出的尺寸或宽高比；
2. 提示词中明确写出的尺寸或宽高比；
3. `platform-specs` 中用途关键词对应的 `provider_aspect_ratio`；
4. 没有匹配时使用平台默认 `1:1`。

像素尺寸只用于业务语义，不传给当前平台。`2.35:1` 按上游规则映射为 `21:9`；其他值只映射到工具 schema 已开放的等价比例。无法无损映射时如实说明，不伪造接近比例。

## 生成与交付

用户需求具体时直接准备报价；缺少主题等决定性信息时用 `ask_question` 追问一次。调用 `generate_image`，传入 `activationId`、简短 `title`、保持原样的 `prompt` 和解析后的 `size`。该工具按本任务已确认的单张 1K 图片项目执行，无需再次费用确认；规格必须与 taskScope 一致。

调用后等待平台完成提交、查询、本地保存和作品交付。成功作品可预览和下载；失败或结果未知时核对原任务，不重新生成。用户要求新方向或规格时另开新任务，不自动重试。

## 本平台边界

只开放单张、1K、无参考图、`gptImage2`。Pro、参考图、图片编辑、mask、透明背景、多图批量、多供应商配置和上传后的后续修改暂不开放。

上游 shell 脚本、`.env`、API Key、供应商 URL、输出目录及 curl/jq 能力都只作为原包归档，不在本平台执行。宿主只通过现有 `generate_image@1`、会员价目、预算、回执和本地作品存储完成调用，不要求用户配置供应商密钥。
